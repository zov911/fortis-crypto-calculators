Crypto compliance calculators

Three lead-generation calculators, ready to share as links or to embed in any page of the website.

Embed on the website (recommended)

Paste this where the calculator should appear. Works in WordPress (Custom HTML block), Webflow (Embed), Wix (Embed code), Squarespace (Code block) or plain HTML. The calculator resizes itself to fit, so there are no inner scrollbars.

Use cost, readiness or savings in data-fortis-calculator. The script tag only needs to be on the page once, even with several calculators.

Options

AttributeValuesWhat it does
data-themelight / darkForces a colour scheme. By default the calculator follows the visitor's system setting.
data-headertrueShows the Fortis brand bar inside the embed (hidden by default because the site already has a header).
data-transparenttrueTransparent background, so the calculator sits on the page's own background.
data-scroll-offsetpixels, default 80Height of a sticky site header, so pop-up forms are not hidden under it.
data-min-heightpixelsSpace reserved before the calculator loads, to avoid layout jumps.

Simple iframe (no script)

If the site does not allow scripts, use a plain iframe with a fixed height. Auto-resize needs the script above.

Analytics

Calculator events are pushed into the website's Google Tag Manager dataLayer with a fortis_ prefix, so GTM triggers can be set up without touching the calculators. No personal data is ever sent to the host page.

EventWhen
fortis_calculator_startFirst interaction
fortis_question_completedEach answer (question id + answer)
fortis_estimate_viewedResult shown (estimate / score)
fortis_pdf_clicked, fortis_proposal_clickedLead form opened
fortis_pdf_submitted, fortis_proposal_submitted, fortis_lead_submittedLead form submitted (conversion)
fortis_book_call_clicked, fortis_share_clickedBooking link or share link used

Each event also carries fortis_calculator (crypto_cost, crypto_readiness or crypto_savings). Developers can also listen for fortis:event and fortis:lead DOM events on the container.

Receiving leads

Lead forms post a JSON payload (answers, estimate, UTM source and contact details) to one webhook URL — for example Make.com, Zapier, HubSpot or a CRM. Until it is connected the forms run in demo mode: the PDF still downloads, but no data is sent anywhere. Set lead_endpoint in assets/fortis-core.js to switch it on. Prices are in the same file.
